### Hi, I'm Hena 👋

MS CS student at NYU Tandon. I build quant research pipelines in Python and full-stack tools that make engineering teams' work easier to see.

**Projects**

- **[momentum-equity-research](https://github.com/Hena3124/momentum-equity-research)**: Backtests 12-1 month momentum against short-term mean reversion across the S&P 500 (momentum 2020–2024, mean reversion 2019–2024), with transaction costs, t-tests and a fixed out-of-sample split. The interesting finding: a concentrated 5×5 long/short book wins 62% of months but is wiped out by two momentum crashes, so concentration and crash risk matter far more than trading costs.
- **[prlens](https://github.com/Hena3124/prlens)**: A full-stack tool that signs in with GitHub and scores every open pull request from 0–100 for risk, using size, files touched, review density, staleness and how many reviewers are requested. It also shows a merge-readiness traffic light and repo-wide review analytics. React + Express, MIT licensed.
- **[AACcommodate API](https://github.com/Hena3124/aac-voice-api)**: Team capstone. A TypeScript library, published on npm as `aac-voice-api`, that lets children who use AAC devices play web games by voice. It turns speech, including synonyms of game commands, into game actions using Whisper, offline in the browser or through a FastAPI backend.
- **[Who Owes Me Money](https://github.com/Hena3124/who-owes-me-money)**: Team project. A React Native app for splitting bills: scan a receipt, OCR (Tesseract.js) parses the items, and the app works out who owes what. Runs on iOS and Android.
- **[Inventory-Management](https://github.com/Hena3124/Inventory-Management)**: Next.js + Firebase Firestore inventory tracker with live quantity updates.
